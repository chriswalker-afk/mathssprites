# PR87 — Wearable cosmetics

Add the 14 planned wearable rewards to the shared visual allow-list. No catalogue IDs, thresholds or storage changes: seven headwear rewards (45,120,300,360,450,570,660), four eyewear rewards (72,180,330,510), three neckwear rewards (18,210,600). The Atelier now shows actual miniature previews for all 18 implemented cosmetics, including the PR85 eyes/fur. Locked items can be tried on; only owned and implemented items can be equipped.

The glasses are fixed to the face while eyes move within their clear lenses. Hats, glasses and neckwear can be combined independently with fur and eyes. No effects on token count, balance mass, layout, moves, or scoring. Main scenes, foyer, native actors in baskets and fraction shadow-root wholes share the same layers; initial static brand art matches runtime. Exact fractional geometry stays unchanged. Fraction presentation revision is 87.

The existing developer art study now displays every wearable on black, white and square sprites, plus a combined outfit. Added/updated tests for all fourteen distinct artworks, bounded art, invisible default layers, owned/locked/unimplemented status, combination and persistence, live signed and fraction scenes, basket transport, and asset versioning.
