# PR66 — Fractional Algebra Apprentice

All 16 planned notebook levels (four chapters) are published, so the Fraction
Workshop now offers all 60 planned levels. The World 3 notebook deliberately
does not route through the old whole/signed editor. It shares the exact
fraction transaction engine, existing campaign registry and scene.

## Student flow

1. Only the paper equation and maths editor are shown. Build an operation
   with sign keys, a whole or stacked-fraction operand, and optional x; or
   type one operation (e.g. −1/2x, −x/2, −(1/2)x, −1 1/2, ×3, ÷2).
2. The original written form remains visible as MathML (including equivalent
   unreduced and mixed forms). The reduced rational quantity is what the
   physical engine validates. A preview calculates the exact next line;
   changing the draft invalidates it. Confirm adds precisely one step.
3. Undo and restart change the checked paper history, never campaign credit.
   No arbitrary expression evaluation, negative object types, decimal
   approximations, fraction scale factors, or unsupported physical pieces.
4. Once the solution is isolated, Watch your sprites reveals the original
   physical room, and the existing hand plays each checked transaction in
   order. It verifies the exact room before and after every move. Credit
   and stars are recorded only on a fully verified replay. Hand tools are
   hidden during replay; home/levels navigation is disabled while it plays.
   The final review uses the existing fraction comic and supports replay
   again, returning to paper, and next level. Repeated credit is idempotent.

## Verification

A legal minimum-length route for each of the 16 levels must attain the
existing algebraic lower bound through the exact notebook parser and
physical transaction engine. Tests cover parser syntax and reductions,
mixed numbers, preview/confirm, invalidation, Undo, typed and structured
entry, all sixteen routes, paper-first visibility, exact replay,
progress/resume, and narrow layouts. The global totals become 180 playable
levels and 540 stars (60 levels and 180 stars in World 3). The old notebook
and save formats are preserved. Manual visual review remains necessary.
