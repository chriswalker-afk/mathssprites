# Visual and animation direction

## World
A two-room balance apparatus built from aged timber, black iron and brushed brass inside a softly illuminated alchemical laboratory. Each room is an open-front dollhouse-scale interior with an independent floor, shelves and background. The rooms move as rigid parts of the scale but their contents bounce independently.

**Mood:** whimsical, tactile, mysterious, calm and clever — for secondary-school students, not preschool.

## Sprite family
- **Round unknown:** near-black charcoal fur silhouette; irregular fuzzy perimeter; two off-white eyes; tiny feet and arms; subtle deformation on landing.
- **Square unknown (future):** rounded-square black fluff silhouette; distinct from round even when monochrome. Explicit `x²` only in replay.
- **Other variable (future):** similar soot material with an unambiguous distinguishing silhouette or small restrained accessory; colour is supplemental, never the only cue.
- Sprite identities stay stable within a level. They are **not** existing copyrighted movie characters; make original shapes, motion and expressions.

## Constant object family
A collection of visually identical pale mineral stones or brass weights, one object = one unit in the first four levels. Do not vary apparent weight or size between unit stones. A visually separate grouped container may be introduced later for tens but must explicitly disclose its value at replay.

## Animation list
- Sprite idle: staggered irregular hops; rare synchronized bounce; looks toward hand.
- Land: compress then spring; subtle tiny soot wisps.
- Hand enter: natural overhead hand, lab sleeve, reach, pinch/lift, place, withdraw.
- Removal: creatures react then one is carefully picked up; no harmful imagery.
- Grouping: gather equal collections into faint brass hoops; select and retain one set on divide.
- Duplication: hand places identical grouped sets into each room; avoid confusing a single lifted item with multiplication of a whole expression.
- Balance: small physical tilt in operation preview / intermediate hand phase, smooth re-levelling after matched transaction.
- Success: sprites briefly settle; dial rests at centre; brass backlight glows; no confetti storm.
- Reveal: chalk labels appear, symbolic equations write onto translucent glass, hand retraces actual moves.

## Layout and production
- Desktop 16:9 main composition; flexible responsive alternative for tablets.
- Preserve readable silhouettes, clear item counts and separation; use a layout algorithm when pieces crowd.
- Layered scene: lab background, scale body, room shells, room items, hand, HUD, reveal overlays.
- Export individual art assets on transparent backgrounds, not full-screen precompositions, to enable real animation.
- Prototype physics with deterministic tweened motion rather than unbounded dynamic collisions.
- Accessibility: high-contrast silhouettes, static-count fallback, reduced motion, keyboard control.
