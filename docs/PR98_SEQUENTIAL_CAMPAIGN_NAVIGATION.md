# PR98 — Campaign choices before levels

Home → Choose a world → Choose how to learn → Choose a level. Reuse the four door illustrations, with mathematical context, completion and stars. Stage cards reuse the medallions, explain each method, and recommend Guided for newcomers without locking other choices. A world choice clears the previous method. Arrows move focus; Enter/Space selects; Escape goes back one step. All 240 level IDs, 720 stars, 57 cosmetics and save keys are unchanged.

Browsing never saves a resume or earns stars. Returning from play goes to the selected board; Next still advances directly. Help, Settings and Atelier preserve the return screen. Equation Workshop remains separate and free-play, with an optional shortcut from levels retained.

PR98 retains the existing chapter tiles and immediate level launch. PR99 builds compact colour-coded numbers and selection-before-play details; PR100 animated method demonstrations and artwork; PR101 responsive and accessibility polish.
