For nonnegative sprite value x, the side ax+b is nonnegative.
The game therefore recovers the principal square root, not both
solutions of an unrestricted quadratic. No negative, irrational,
fractional or higher-power objects are added by this PR.

## Rejected roots

An illustrative whole-object trial uses a plausible bounded square frame
with integer sides. Prefer existing perfect-square corners; infer a
plausible constant-side length from the mixed coefficient when the
constant corner is incomplete. It is a visual diagnostic, not an
optimal solution search or automatic completing-the-square hint.

- Missing pieces leave dashed empty cells, never invented objects.
- Transposed mixed positions are filled alternately, exposing uneven
  mixed regions; surplus objects sit in a small leftover tray.
- Every original object maps once to a present cell or tray slot.
  Keep the original floor state untouched and visually hidden while
  the trial is shown. Explain the precise missing or extra objects
  only after the physical attempt, then restore the original floor.
- E.g. x²+4x+3 has one missing weight; x²+3x+4 has one missing
  mixed-region sprite; 12 weights can fill a 3x3 square with three
  left over. These are restrictions of whole-object representation,
  not statements that the mathematical square root does not exist.
- Signed, fractional and crate cases retain the prior refusal path.
